# Veno Live Studio

Programa leve para Linux desenvolvido pela Veno Studio Network.

O Veno Live Studio permite gravar a tela do computador e realizar transmissões ao vivo para o YouTube.

## Recursos

- Gravação de tela em MP4 e MKV
- Transmissão ao vivo para o YouTube via RTMPS
- Cenas e camadas
- Texto, imagens e vídeos sobre a transmissão
- Relógio na tela
- Marca-d'água V VENO LIVE
- Controle de bitrate
- Resolução automática entre 480p e 1080p
- Detecção automática do processador
- Modo econômico para computadores com poucos recursos
- Controle de áudio e volume
- Contador de duração da transmissão

## Sistemas compatíveis

- Tiger OS
- Ubuntu
- Debian
- Linux Mint
- Distribuições baseadas no Ubuntu ou Debian
